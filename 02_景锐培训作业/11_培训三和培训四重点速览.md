# 景锐培训三、培训四重点速览

> 来源：`01_原始材料/第六期景锐课件/主题三：培养与沟通.pptx`、`01_原始材料/第六期景锐课件/主题四：激励与引导.pptx`
> 整理日期：2026-08-24
> 使用场景：没时间细看课件时，快速把握“培养、沟通、激励、引导”的核心方法，并转化为链路层科室可落地的管理动作。

## 一句话结论

培训三解决的是“怎么带一个真实的人，在真实任务中成长，并通过关键沟通形成行动共识”；培训四解决的是“怎么看懂不同类型成员的真实状态，用差异化激励和引导方式把人重新调动起来”。

对当前链路层科室最有用的一句话是：

> 先看清人，再安排事；先诊断差距，再设计培养；先理解状态，再提出要求；先设计环境，再期待改变。

## 培训三：培养与沟通

### 1. 课程主线

培训三不是重新讲理论，而是把方法放回一个真实组员、一个真实任务、一段真实沟通里去验证。

核心路径是：

```text
ASK识别差距 -> 721设计培养 -> OJT带教动作 -> 关键沟通 -> 复盘调整
```

这门课强调：问题通常不是“不知道方法”，而是回到工作里，面对某个具体的人，不知道该用哪个方法。

### 2. 培养不是“多培训”

培训三把培养拆成四类动作：

| 方法 | 解决什么问题 |
| --- | --- |
| ASK | 判断成员到底差在哪 |
| 721 | 设计成长方式，不只靠上课 |
| OJT | 在真实任务中教会他 |
| IDP/成长计划 | 把成长目标写清，并持续跟进 |

真正顺序是：先判断差距，再设计成长路径，最后在真实任务里带。

### 3. ASK：别把所有问题都叫“态度问题”

成员交付不稳定时，不要第一反应就定性为“不认真”。要先拆差距：

| 看到的现象 | 可能的真实差距 | 管理动作 |
| --- | --- | --- |
| 不知道怎么做 | 知识差距：不了解流程、标准、背景 | 补背景、讲流程、给标准 |
| 做了但质量不稳 | 技能差距：缺少练习、示范、反馈 | 安排小任务练习，现场示范，短周期反馈 |
| 不敢做、不愿做 | 状态/意愿差距：信心、压力、动机、情绪问题 | 先沟通状态，再给支持和边界 |
| 换个场景就失效 | 适配问题：任务、压力、环境、资源不匹配 | 调整任务难度、资源和检查方式 |

提醒：如果用“批评”处理“不会”的问题，只会让成员更不敢暴露问题。

### 4. OJT：不是“教过”，而是“带到能独立”

OJT 的关键是根据成员当前阶段调整带教方式：

| 阶段 | 你要做什么 |
| --- | --- |
| 不会 | 说给他听，做给他看 |
| 会一点 | 让他做做看，你在旁边观察 |
| 能做但不稳 | 给具体反馈，让他改一轮 |
| 能稳定交付 | 放手，但保留检查点和支持 |

真正的放手不是不管，而是目标、边界、检查点和支持都已经说清楚。

### 5. 721：培养要落在真实任务上

| 比例 | 方式 | 要点 |
| --- | --- | --- |
| 70% | 实践 | 安排真实、难度合适的任务，让成员在工作中练 |
| 20% | 指导 | 你、骨干、同事给他示范、反馈、复盘 |
| 10% | 学习 | 文档、课程、知识分享、规范学习 |

没有真实任务的培养，容易停留在“听懂”；没有指导和反馈的真实任务，又容易变成成员自己撞墙。

### 6. 培养最容易犯的三个错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 只讲方法，不安排真实练习 | 成员听懂但不会用 | 给一个两周内可完成的小任务 |
| 只看能力，不看任务和场景是否匹配 | 把人放进不适配场景，挫败感加重 | 评估任务风险、压力、资源和支持条件 |
| 只在出问题后批评 | 成员不敢提前暴露风险 | 提前设置支持和检查点 |

### 7. 组员不主动沟通，先改机制

课件案例里，组员不主动沟通常见原因包括：

- 不知道哪些节点必须同步。
- 不知道哪些风险必须提前暴露。
- 以前提前暴露风险后，先被批评，导致不愿早说。
- 没有低成本、固定化的沟通节奏。

组长先做三件事：

1. 明确同步规则：哪些节点必须主动同步，哪些风险必须提前暴露。
2. 先处理问题：提前暴露风险时，先一起解决，再讨论责任。
3. 固定低成本节奏：每周或关键节点前用 10 分钟，只看风险、卡点和需要支持。

可直接照做：

```text
每周三 16:30，用 10 分钟确认三件事：
1. 本周最大风险是什么？
2. 需要谁提供支持？
3. 是否影响当前节点？
```

### 8. 关键沟通五步法

沟通不是把话说出去，而是减少信息不对称，形成行动共识。

| 步骤 | 做什么 |
| --- | --- |
| 1. 说事实 | 我观察到了什么，不先下结论 |
| 2. 听感受 | 你怎么看，你卡在哪里 |
| 3. 做澄清 | 我理解得对不对，还有没有遗漏 |
| 4. 对期待 | 目标、边界、支持怎么对齐 |
| 5. 定行动 | 谁做什么，何时回看 |

最容易犯的错误是直接跳到“你应该怎么做”。

### 9. 向上沟通三句式

当你判断问题不在成员，而在任务与资源冲突时，不要简单说“下面人不够，活做不了”。建议用三句式：

```text
1. 摆事实：
当前A、B、C三项工作都被要求P0，同时保住预计风险是____。

2. 给影响：
如果全部并行，最可能影响的是____，预计延迟/质量风险是____。

3. 要决策：
请确认优先保哪项、允许牺牲什么、需要协调谁。
```

沟通不能创造资源，但能让资源冲突更早进入决策。

### 10. 骨干抵触任务，先谈清四件事

能力强的人不是不需要管理。很多时候，骨干更需要被认真沟通。

当骨干抵触紧急挑战任务时，不要急着说服他接任务，先确认：

| 要确认的事 | 具体问题 |
| --- | --- |
| 事实和变化 | 我观察到哪些具体变化，而不是给他扣“态度差”帽子 |
| 真实困难 | 是负荷、认可、授权、边界，还是情绪积累 |
| 边界与支持 | 这件事必须做到什么，你能给什么支持，哪些要向上协调 |
| 回看时间 | 谈完后下一步做什么，什么时候再确认 |

沟通结束前可以问：

```text
我们确认一下，你下周先做什么？
我需要提供什么支持？
我们哪天再回看？
```

### 11. 培训三对链路层科室的转化

| 对象 | 建议动作 |
| --- | --- |
| 湘湘 | 按授权式培养，让她牵头组网方向任务拆解和日常拉通；你保留关键节点把关和支持 |
| 任霜 | 先认可她在资源管理方向的经验价值，再要求交接包、风险台账和符兵带教动作 |
| 汪泰利 | 先用 ASK 判断是知识、技能还是信心问题，再给边界清楚的小模块任务 |
| 符兵 | 采用 721 + OJT，跟资源管理真实任务走一轮，不只看文档学习 |
| 周非凡 | 以全向链路层主线培养，安排文档、小需求、复盘、需求分析等阶梯任务 |
| 你自己 | 下属带问题来时，先问“你怎么看”“你准备怎么处理”，避免责任转移到自己身上 |

## 培训四：激励与引导

### 1. 课程主线

培训四讲的是：管理者不能只靠压任务、讲道理、发奖金来带团队，而要先做人才盘点，再按不同类型成员设计差异化激励和引导方式。

核心路径是：

```text
人才分类画像 -> 分层激励 -> 正向管理 -> 选择架构式引导 -> 落地行动计划
```

### 2. 人才分类：能力 × 意愿

课件用两个标尺给成员画像：

- 能力高低：专业技能、解决复杂问题的经验、学习和应变能力。
- 干事意愿：工作热情、主动担责态度、成就渴望和自驱力。

四类成员画像：

| 类型 | 特征 | 管理重点 |
| --- | --- | --- |
| 核心骨干：高能高愿 | 专业优势突出，愿意扛事，但不善表达委屈，心寒后可能默默离开 | 授权、看见、谈心 |
| 青年潜力：低能高愿 | 有热情、愿意钻研，但经验不足，经不起连续挫败 | 阶梯任务、容错、肯定进步 |
| 倦怠老将：高能低愿 | 业务功底扎实，但降低预期，只守本职，不愿额外承担 | 公平分工、唤醒初心、重塑价值 |
| 基础执行：低能低愿 | 只求安稳，进取心不强，能力有限但状态平稳 | 明确职责、基础辅导、稳定交付 |

注意：标签只是管理假设，不是给人盖章。真正使用前要通过 1 对 1 校验。

### 3. 激励不是奖励

激励的本质是激发一个人内心深处的动力和潜能。钱不是没用，但不是所有场景都有效。

金钱有效的条件：

- 公平。
- 正是员工最需要的时候。
- 不只是钱，还承载认可。
- 达到或超过预期。
- 与绩效贡献相关联。

金钱容易失效的情况：

- 不是最需要的时候。
- 数额与预期差距大。
- 干得多拿得少，干得差反而拿得多。
- 不知道为什么发。
- 兑现遥遥无期。

### 4. 激励手段要覆盖不同需求层次

| 需求层次 | 可用手段 |
| --- | --- |
| 基础需要 | 酬劳、待遇、工作条件 |
| 安全感 | 标准、程序、游戏规则、分工明确、信息、培训、工具 |
| 社会需要 | 管理支持、集体生活、价值认同、共同成功 |
| 被尊重 | 头衔、荣誉、积极肯定、提高身价 |
| 自我实现 | 挑战性任务、自主权、承担责任、授权 |

对研发团队来说，很多时候“规则清楚、被看见、有授权、有成长路径”比一次性的口头表扬更有持续激励作用。

### 5. 七种非物质激励工具

| 工具 | 重点 |
| --- | --- |
| 目标激励 | 目标具体、有挑战、有反馈，员工参与目标讨论后更容易转化为个人责任 |
| 文化激励 | 激活使命感、责任感、价值感、存在感、获得感 |
| 关爱激励 | 倾听压力、关注情绪、给予必要支持 |
| 竞争激励 | 优秀者优先、能干者能上、资源向一线贡献者倾斜 |
| 荣誉激励 | 设计荣誉称号、评选流程、奖品和颁发仪式 |
| 认可激励 | 对正向行为、绩效结果、个人成长、管理优化、长期忠诚及时认可 |
| 发展激励 | 提供晋升通道、分层培训、专属头衔和成长机会 |

### 6. 四类成员的差异化激励

**核心骨干：授权与看见**

管理动作：

- 充分授权，管住质量、交付、合规底线，技术方案和执行细节给自主空间。
- 在复盘、评优、向上汇报中显性呈现骨干贡献。
- 用提问代替指令，激发专业自尊和主人翁意识。
- 常态化谈心，关注疲惫、诉求和压力。

常见误区：

- 无休止增加工作量。
- 频繁插手技术细节。
- 只盯结果，不问过程压力。

**青年潜力：容错与成长**

管理动作：

- 阶梯式布置任务，从辅助工作到独立模块，再逐步参与核心攻关。
- 区分探索性错误和责任心错误，宽严有度。
- 用连续提问引导他自己发现问题，训练独立思考。
- 及时肯定进步，保护热情。

**倦怠老将：唤醒与公平**

管理动作：

- 优化分工，打破少数人负重、部分人清闲的不均衡。
- 一对一倾听委屈和顾虑，先建安全区，再谈要求。
- 匹配专项业务，让他重新找到被需要的价值感。
- 遇到难题时用请教式问题激发参与感。

底线：

- 接纳阶段性疲惫，但不能让“躺平”成为团队常态。
- 评价机制要让担当者获得更多机会。

**基础执行：明确与稳定**

管理动作：

- 不反复拔高标准，接纳能力现状。
- 明确岗位职责和量化交付标准。
- 做好基础业务辅导。
- 肯定踏实履职，维持基础业务稳定输出。
- 用清晰流程和标准减少决策负担。

### 7. 正向管理四条原则

| 原则 | 含义 |
| --- | --- |
| 对事严格，待人温和 | 业务风险和质量短板必须较真，但批评只针对工作问题，不否定个人价值 |
| 兼顾过程激励 | 研发周期长、变数多，不能只看最终结果，也要看过程努力和阶段进步 |
| 分类施策，守住公平 | 差异化管理不是不公平，而是让每个人在适合的位置发挥价值 |
| 多给方法路径，少做负面否定 | 说“不行”时，要同时告诉“怎样才行” |

### 8. 为什么说服常常失效

课件的核心判断是：人不是先理性判断再行动，而是先有情绪，再找理由。讲道理越充分，对方防御心理可能越强。

新晋管理者常见三个误区：

- 习惯纠错，缺少认可。
- 管理手段一刀切。
- 只会加压，缺少疏导。

真正有效的方式不是强行改变别人，而是设计环境，让对方自己产生改变动机。

### 9. 选择架构：用环境设计替代硬说服

选择架构的核心是：人不是只在选择选项，也是在选择你呈现给他的选项结构。改变信息呈现方式，就可能改变决策结果。

信息环境设计有四个变量：

| 变量 | 操作要点 |
| --- | --- |
| 信息接触顺序 | 先铺背景，再给案例，最后提出正式建议，避免一上来就硬推 |
| 接收信息时的情绪状态 | 选择安全、放松、被肯定的状态沟通，避免在刚被批评后提要求 |
| 接触信息时的在场者 | 借助资深同事、同伴示范和自然分享，让成员从“被说服”变成“主动询问” |
| 陈述与问题的差异 | 少陈述结论，多提问题；陈述容易激起防御，问题更容易激发参与 |

认知场四步铺设法：

1. 明确目标：不是让对方按你说的做，而是让对方产生内在动机。
2. 松动信念：找到支撑现有行为的核心信念，逐步让对方意识到问题。
3. 自然切入：用日常场景、他人案例、你自己的示范慢慢植入信息。
4. 提出问题：等信息发酵后，用问题激活对方自我反省。

边界提醒：影响力要服务于对方成长和共同目标，不能变成操纵。真正的影响力会建立长期信任，操纵只会损害关系。

### 10. 培训四对链路层科室的转化

| 对象 | 画像假设 | 激励与引导动作 |
| --- | --- | --- |
| 湘湘 | 核心骨干 | 给组网方向授权和主角感；在周会、复盘、向上汇报中显性呈现她的贡献；让她参与关键方案判断 |
| 任霜 | 高能力成员，需尊重和支持 | 不简单贴“低意愿”标签；先认可资源管理经验价值，再把交接包包装成团队资产和个人专业沉淀 |
| 汪泰利 | 能力待提升，需明确边界 | 给清晰、低歧义的小模块任务；用短周期检查和正向反馈建立信心 |
| 符兵 | 青年潜力 | 用阶梯任务和容错机制培养资源管理能力；错误以复盘和改进为主 |
| 周非凡 | 新入职潜力成员 | 主线放全向链路层；从文档、小需求、问题复盘、需求分析切入，给清晰成长路径 |
| 你自己 | 管理者 | 通过人才画像、1 对 1、工作重排，减少“骨干无限加压”和“弱项长期闲置” |

## 三十天落地建议

### 第1周：做人才画像和培养诊断

输出一张内部表：

| 成员 | 能力判断 | 意愿判断 | 当前画像 | 主要差距 | 下一步动作 |
| --- | --- | --- | --- | --- | --- |
| 湘湘 | 高 | 待确认 | 核心骨干 | 是否负荷过高、授权是否充分 | 单独沟通组网方向授权和支持 |
| 任霜 | 高 | 待确认 | 高能力成员 | 产假前交接压力、资源方向知识显性化 | 明确交接包和符兵带教节奏 |
| 汪泰利 | 待提升 | 待确认 | 需诊断 | 知识/技能/信心需拆分 | 给一个明确小模块和检查点 |
| 符兵 | 中低 | 高 | 青年潜力 | 资源管理知识和实战经验不足 | 跟任霜做真实任务 |
| 周非凡 | 待培养 | 高 | 青年潜力 | 全向链路层经验不足 | 安排全向文档、小需求、复盘任务 |

### 第2周：完成两次关键沟通

建议优先做：

- 和湘湘谈：授权、边界、支持、回看时间。
- 和任霜谈：交接包价值、符兵带教动作、产假前最小闭环。

每次谈完必须形成两项行动约定和一个回看时间。

### 第3周：把培养落到真实任务

建议选两个最小任务：

- 泰利：承接湘湘拆解后的一个组网小模块，按 99/50/1 检查。
- 符兵：跟做资源管理一个中低风险功能或问题处理，任霜示范、符兵复述、你抽查。

### 第4周：做一次复盘和工作重排

复盘问题：

- 哪个成员的判断被修正了。
- 哪个任务分派不匹配。
- 哪个骨干负荷过重。
- 哪个成员可以承接更明确的责任。
- 哪条规则需要沉淀成周会、AB角或自测试机制。

## 没时间时先记住这十条

1. 培养先做 ASK 诊断，不要把所有问题都当态度问题。
2. 721 不是口号，70% 必须是真实任务，20% 必须有反馈和复盘。
3. OJT 的目标不是“教过”，而是“带到能独立”。
4. 组员不主动沟通，先建立同步规则和安全反馈环境。
5. 关键沟通要说事实、听感受、做澄清、对期待、定行动。
6. 向上沟通要摆事实、给影响、要决策。
7. 激励先做人才盘点，不能一套方法管所有人。
8. 骨干要授权和看见，青年要容错和成长，老将要公平和唤醒，基础执行要明确和稳定。
9. 说服常常失效，引导要靠信息顺序、情绪状态、在场者和提问方式设计。
10. 你当前最该做的是人才画像、1 对 1、AB角真实任务、骨干授权和工作重排。
