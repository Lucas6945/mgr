# 景锐培训作业

本目录保存景锐培训相关作业和学习实践材料。这里的文档保留“作业题型 + 结合链路层科室实际的答案”，方便后续结业提交、复盘和二次修改。

## 文档清单

| 文档 | 用途 |
| --- | --- |
| [01_目标与过程管理作业.md](./01_目标与过程管理作业.md) | 对应 SMART、四象限、目标拆解、肯定/改善反馈、重点工作检查表等作业 |
| [02_培养与沟通作业.md](./02_培养与沟通作业.md) | 对应差异化领导、AB角培养、1对1沟通、技术冲突处理和人员反馈作业 |
| [03_综合实践笔记.md](./03_综合实践笔记.md) | 早期综合整理，保留较完整背景和管理思考 |

## 拆分原则

- 作业文档要能直接复制、修订、提交。
- 早期作业或综合笔记中的人员安排可能带有历史版本痕迹；涉及周非凡、社招名额、定向/全向分工时，以 [../05_项目规划与风险/2026年度链路层科室人力配置与重点工作决策.md](../05_项目规划与风险/2026年度链路层科室人力配置与重点工作决策.md) 为准。
- 机制化内容不要只留在作业里，应同步沉淀到 [../03_科室管理机制/](../03_科室管理机制/)。
- 涉及具体人员交接或个人沟通的材料，应同步沉淀到 [../04_人员梯队与沟通/](../04_人员梯队与沟通/)。
