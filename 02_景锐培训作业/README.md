## 拆分原则

- 作业文档要能直接复制、修订、提交。
- 早期作业或综合笔记中的人员安排可能带有历史版本痕迹；涉及周非凡、社招名额、定向/全向分工时，以 [../05_项目规划与风险/2026年度链路层科室人力配置与重点工作决策.md](../05_项目规划与风险/2026年度链路层科室人力配置与重点工作决策.md) 为准。
- 机制化内容不要只留在作业里，应同步沉淀到 [../03_科室管理机制/](../03_科室管理机制/)。
- 涉及具体人员交接或个人沟通的材料，应同步沉淀到 [../04_人员梯队与沟通/](../04_人员梯队与沟通/)。
- 如果一个文档同时是“培训作业”和“具体人员沟通材料”，完整作业归档在本目录；长期执行口径、检查清单和风险预案沉淀到 `04_人员梯队与沟通/`。
