## 维护规则

1. 原始文件保留在本目录，不直接改写为结论。
2. docx 转换出的 Markdown 若保留作业题型和答案，放入 `02_景锐培训作业/`。
3. 从原始材料中提炼出的稳定机制，放入 `03_科室管理机制/`。
4. 涉及具体人员培养、交接、沟通和风险预案的可执行材料，放入 `04_人员梯队与沟通/`。
5. 涉及年度人力、项目优先级和风险决策的结论，放入 `05_项目规划与风险/`。
