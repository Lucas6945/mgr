## 维护规则

1. 原始材料只放入 `01_原始材料/`，不在原始材料上直接改写结论。
2. 培训作业放入 `02_景锐培训作业/`，保留题型、输入答案和可交付表达。
3. 可长期运行的管理机制放入 `03_科室管理机制/`，要求有责任人、节奏、检查点和验收标准。
4. 涉及具体人员的培养、交接和沟通材料放入 `04_人员梯队与沟通/`。
5. 涉及项目、人力、年度重点工作和风险预案的材料放入 `05_项目规划与风险/`。
6. 可复用空表、话术和检查表放入 `06_模板库/`。
7. 若早期文档和最新项目决策冲突，以 [2026年度链路层科室人力配置与重点工作决策.md](./05_项目规划与风险/2026年度链路层科室人力配置与重点工作决策.md) 为准。
